# 125 bilingual Political Science tests

Planned: 20 questions per test; 4 book-based questions and 16 new practice questions. Questions, options and explanations will be bilingual. No completed test workbooks have been exported yet.

The Questions sheet will use the website's exact 14 columns. Unit values will match the existing admin selectors. These are topic practice tests, not full-length state-specific exam simulations.
