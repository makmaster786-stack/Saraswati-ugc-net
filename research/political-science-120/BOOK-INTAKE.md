## Conversion issues

Hindi glyph extraction differs materially from the visible text. Examples on page 1: the visible question marker प्रश्न is extracted as Ůʲ, and सिद्धांत contains Ƞ in extracted text. Across the book, many extended Latin/IPA symbols replace Indic conjuncts. The short-i vowel is also extracted in visual rather than logical order in some words. A blind string export would produce malformed Hindi text.

Question explanations and matching-list structures span page breaks and two columns. These require language-aware column extraction and structure validation. The visible page-1 English/Hindi fourth option for question 2 differs in the extracted text, illustrating the need to preserve/review each language independently.

With only book questions and no repeats, 120 tests averaging 15–20 questions require at least 1,800–2,400 usable items. The initial count does not support that allocation. User preference was requested for revision repeats, original additional questions, or shorter tests. This decision remains pending.

For reliable bilingual text conversion, request the editable Word document used to generate the PDF (PDF metadata title identifies a Microsoft Word source), or a spreadsheet containing the underlying questions. Do not manufacture clean-looking Hindi with unresolved glyph substitutions or export empty/duplicated files as a completed 120-test series.
